研究流水线

数据从原始行情流转到最终报告，共 10 步。每一步标注了算法、输入、输出与命令行入口。

① 数据获取 fetch

从行情数据源下载美股日线行情，落盘为原始 Parquet。

算法Massive API → 日线 OHLCV（open/high/low/close/volume/vwap）
输入tickers、start、end、timespan、multiplier
输出data/raw/daily_bars.parquet
命令alpha-lab fetch --config <config>

② 因子计算 factors

在原始行情上叠加全部已启用因子，并计算横截面排名与 z-score。

算法公式因子（动量/波动/量价/位置等）+ add_cross_sectional_ranks（截面分位数排名 + z-score）
输入data/raw/daily_bars.parquet
输出data/processed/factors.parquet
命令alpha-lab factors --config <config>

③ K 线路径 token（实验）

把 OHLCV 路径离散成 K 线 token，生成独立的路径表征因子，不覆盖主因子池。

算法涨跌幅桶 + 振幅桶 + 成交量冲击桶 + 收盘位置桶 → 20/60 日 entropy、n-gram、状态转移、路径相似度
输入data/raw/daily_bars.parquet
输出data/processed/kline_sequence_factors.parquet
命令alpha-lab kline-factors --config <config>

④ K 线路径发现 discover-kline-patterns（实验）

批量枚举 K 线 token 的状态、转移和组合模式，寻找公共价格行为因子解释不了的路径候选。

算法单状态/状态转移/组合 token → 滚动出现频率 → 原始 IC → 对 range_compression、gap_pressure、intraday_quality 正交 IC → discovery_score 排序
输入data/processed/kline_sequence_factors.parquet + data/processed/factors.parquet
输出reports/kline_discovery/kline_pattern_candidates.csv
命令alpha-lab discover-kline-patterns --config <config>

⑤ 隐藏参与者状态 latent-participants（实验）

用日线 proxy 做低频版 HMM/Bayesian filtering，估计机构吸筹、派发、被迫卖出、做市压力、套利修复、噪声交易等状态概率。

算法成交量冲击 + 跳空 + 日内强弱 + 振幅 + 收盘位置 + 5 日趋势 → 状态原型 Gaussian emission → HMM 递推平滑 → alpha_latent_*_prob
输入data/raw/daily_bars.parquet
输出data/processed/latent_participant_states.parquet
命令alpha-lab latent-participants --config <config>

⑥ 统一实验检验 validate-experiment

所有独立实验产物都接入同一套检验入口，避免 K 线、隐藏参与者、ML 候选各自写一套不可比较的标准。

算法实验 alpha_* 列 → 覆盖率 → IC / Newey-West t → 分位单调性 → 正交 IC → 扣费多空回测 → 分年稳定性 → 五关 verdict

命令alpha-lab validate-experiment <experiment-path> --config <config>
