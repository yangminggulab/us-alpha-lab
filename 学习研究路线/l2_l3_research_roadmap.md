## 数据快照事实（决定能做什么）

当前 11 个完整交易日（20170123–20190102），每个完整日单日规模约：

| Stream | 字段要点 | 规模 |
| --- | --- | --- |
| `行情.parquet` | 10 档盘口快照 | ~950 万行 / 3072 只 |
| `逐笔委托.parquet` | order_id、量价、type | ~1500 万行 / 1751 只 |
| `逐笔成交.parquet` | bs_flag、**ask_order_id / bid_order_id** | ~1980 万行 / 2879 只 |

关键点：逐笔成交带买卖双方 order_id，可回连逐笔委托，重建每笔订单生命周期（成交/撤单/驻留/拆分）。这是"有几股势力"类研究区别于普通 tick 数据的原料。

**限制**：11 天且横跨 2017–2019（T+1、流动性结构不同于当下）。够跑方法原型与信号检测，不足以下正式稳健结论。

## 各方向：研究什么 × 怎么赚钱

四个方向不是四条平行的路，是一条逐渐逼近"谁在交易"真相的递进链。① 看盘口 → ② 看成交流真伪 → ③ 看订单生死拆穿假盘 → ④ 把前面全拼起来回答"谁在主导、几股势力"。前三层各自能小赚或降风险，④是把它们组装成可讲故事的因子和择时的地方。

### ① 盘口快照特征 —— 研究"盘口长什么样"

**研究什么**：只看 `行情.parquet` 的 10 档深度，衡量盘口供需失衡。

```
depth imbalance   DI = (V_bid − V_ask) / (V_bid + V_ask)      // 买盘厚还是卖盘厚
OFI(订单流不平衡) = 买档挂量净增 − 卖档挂量净增              // 谁在加码谁在撤
microprice        = 内外盘量加权中位价                         // 比 last 更稳
```

**怎么赚钱**：DI/OFI 是分钟级方向的领先指标；但 A 股 T+1、散户做不了做市，这条单独赚不了大钱。定位是地基：给日内 T+0 回转、给后续每层当输入。单独押它 = 和量化大厂拼速度，死路。

### ② 成交流特征 —— 研究"谁真的在成交"

**研究什么**：`行情`只是挂单，`逐笔成交`才是被吃掉的真钱；`bs_flag` 告诉你每笔是主动买还是主动卖。

```
主动买卖失衡   active_imbalance = (V^主动买 − V^主动卖) / V总
VPIN(知情交易概率) = 按量桶切的主动失衡波动 → 信息交易浓度
单笔金额集中度     = 大单/超大单占比
```

**怎么赚钱**：
- VPIN 高 → 流动性快枯竭 → 风控/预警（躲过大跌就是利润）。
- 上涨但主动卖占优 = 派发；下跌但主动买 = 吸筹 → 给所有量价信号做"真伪过滤"。
- 单独也是子策略，但最大价值是当**标签**（某段是健康上涨还是出货），供 ③④ 校正。

### ③ 委托生命周期重构 —— 研究"哪些单是真的"

**研究什么**：把逐笔成交的 `order_id` 回连逐笔委托，给每笔订单验尸——被吃、撤了、还是挂着。

```
撤单率   π_w = 撤单量 / 委托量          // 挂而不买 = 试探
驻留时间 τ̄_w = 平均订单存活时长         // 挂一下就撤 = 搅局
冰山拆单 = 检测同方向连续等量小单       // 大资金藏身
```

**怎么赚钱**：盘口深度会被钓鱼单污染（挂大单骗你进场、成交前撤掉）。算出哪些量是虚挂，就能把 ① 的 DI/OFI **洗干净**——减假信号直接等于减回撤。同时拆单识别主力建仓痕迹 = 早期介入线索。它是 ④ 的原料库，独立价值是"盘口去假"。

### ④ 势力识别 —— 研究"现在谁在主导"

**研究什么**：把 ③ 重建的订单行为 + ② 的成交压力，在分钟窗口上叠成状态序列，问：当前由几类人主导、各是什么风格。方法细节见下方「主线④落地方案」。

**怎么赚钱**（建立在 ①②③ 之上）：
1. **状态择时**：识别出"机构吸筹状态"（低主动卖、撤单少、持续买）就持仓，识别到"派发状态"就走。这是日线 `latent_participant` 的内日升级——从"上周是谁在搞"变成"当下这个分钟是谁在搞"，故事连贯。
2. **状态作条件 / 作因子**：只在有明确主导吸筹势力的股票上跑短策略提高信噪比；或把状态占比、状态转移概率做成**截面选股因子**，与日线因子互补。
3. **研究叙事**：唯一能从 A 股逐笔讲出完整闭环研究叙事（微结构问题 → 状态空间模型 → 可检验的 K → 可解释标签）的方向。对凯读/华道这类面试，这个叙事本身就是"赚钱"。

**研究归类定位**：④ 属于量化研究里的**市场微观结构（Market Microstructure）**，具体是其中推断交易者意图与数量的 Informed Trading / Order Flow Toxicity 识别。学术锚点：Easley–O'Hara 一脉 + VPIN、Hasbrouck TAQ 建模、HMM Regime（Kritzman–Page）把观测从宏观量价换成订单层特征。业界身份是"机制层研究"：它不是单个 alpha 因子，而是**能解释 alpha 来源**的微观结构模型——同一套特征既能当日内择时，又能当截面因子。简历标签同时命中"微观结构"与"状态空间/ML"。

## 主线④「有几股势力」落地方案

### 定义

日内窗口 `w`（建议 1 分钟，逐 stock-day 拼接）订单行为向量 `x_w`：

```
买卖主动成交失衡:   I_w = (V_buy^act − V_sell^act) / V_w
单量集中度(Herfindahl): H_w = Σ_i (v_i / V_w)²        // 一笔大意图 vs 摊成小单
撤单率:              π_w = Q^cancel_w / Q^submit_w
平均驻留时间:         τ̄_w = mean(订单存活时长)
追价/被动比例:        a_w = V^act_w / V_w              // 主动吃单占比
```

### 先回答「几只」，再回答「是谁」

- **4a 静态聚类**：把每笔订单用 `(金额 v, 驻留 τ, 是否撤单, 单边连续买卖一致性)` 聚类，势力数 = 有效簇数（silhouette / eigengap）。
- **4b 状态空间定 K**：`x_w` 序列建 HMM，状态 `k∈{1..K}` 代表一类主导参与者风格，模型选择定 K：

  ```
  BIC(K) = −2·ln L̂_K + m_K·ln N         取最小 BIC 的 K =「当前有几股势力」
  ```

  已有基础：`../src/us_alpha_lab/latent_participant.py` 里日线 5 状态 HMM（吸筹/派发/被迫卖出/做市/套利修复）。升级路径 = 观测从日线因子换成日内 `x_w`，K 从拍脑袋 5 改成 BIC 自动选。同一思想的内日升级，面试可讲成一个连贯故事。
- **4c 贴标签**（用语义原型做匹配）：
  - 机构/算法：大意图拆中单、高撤单、高驻留、改价重挂。
  - 散户：小单低驻留、高 `a_w`。
  - 做市/流动性：双向高挂撤、低净流 `I_w`。
  - 状态 × 标签交叉表 = 盘面是几股势力博弈、各占多少主动率。

## 诚实警告

11 天样本 + 2017–2019 年代数据，方法学能验证"A 股逐笔能否数出势力数"，结论不能外推到当下。定位是面试研究叙事 + 管线原型，不是实盘结论。待数据补到近期/更多连续日后，再谈稳健性。
